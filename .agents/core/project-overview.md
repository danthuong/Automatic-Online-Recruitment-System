# Project Overview

Automatic Online Recruitment System with Anti-Cheat

Main components:
- Web Portal (HR + Candidate)
- Backend (API + Queue + Orchestrator)
- AI Engine (LLM + CV + Proctoring)
- Electron App (Secure Testing Environment)

Pipeline:
1. CV Parsing & Ranking
2. Queue & Notification
3. Test Generation
4. Anti-Cheat Monitoring
5. Auto Grading
6. HR Dashboard
